# 深海大亂潛 🤿

2–10 人手機連線派對遊戲（潛水主題）。每個人畫面上有 4 個潛水機關（按鈕、開關、滑桿、指北針），但你的指令永遠在**潛伴**的機關上——只能大聲喊出來！氣瓶從 100 bar 開始，按錯或太慢會扣氣，降到 20 bar 全員緊急上升。

## 資料夾結構

```
magic-factory/
├─ server.js            後端（房間、分發機關、指令、驗證、計時）
├─ package.json
├─ data/devices.json    50 個潛水機關題庫（可自己增減）
└─ public/
   ├─ index.html        手機介面
   ├─ css/style.css     海洋背景、寫字板、裝備面板、機關動畫
   ├─ js/client.js      連線與畫面邏輯、音效、震動
   └─ assets/           （放你用 AI 生成的底圖）
```

## 三種難度（船長在大廳選）

| 難度 | 機關 | 指令秒數 | 扣氣／補氣 | 特殊 |
|---|---|---|---|---|
| 🐠 體驗潛水（低） | 按鈕、開關、滑桿（固定目標，聽名字就好） | 20 → 14 秒 | 亂按 −2、逾時 −4、完成 +3 | 沒有失控模式 |
| 🐬 進階潛水員（中） | 三段式開關、隨機滑桿、4 方位指北針 | 15 → 9 秒 | −4／−6／+2 | 最後 30 秒洋流失控 |
| 🦈 技術潛水（高） | 按一下／連按三下／長按、0～10 刻度、8 方位指北針、選擇器 | 12 → 6 秒 | −5／−8／+1 | 最後 45 秒失控＋潛水事故（面鏡起霧、洋流打亂、氮醉） |

各難度的數值都可以在後台「遊戲參數」調整。

**指北針怎麼操作：** 手指往要的方向「滑一下」就定位（單點不算）。高難度偶爾出現「按住○○，保持在X！」：按住指北針拖到該方向，頂住洋流讓指針停 1.5 秒，外圈集滿才算完成。

## 三個潛點＋水面休息

一局分成 3 個潛點（例如 小琉球 → 綠島 → 深藍斷崖），每段之間有 6 秒「水面休息」：
所有人的機關**整組換新**、氣瓶補 5 bar，指令也越來越快。休息時間不算在潛水時間裡。
（後台「一局分幾個潛點」可以改成 1～5，改成 1 就是不分段。）

## 機關故障

| 故障 | 出現難度 | 怎麼辦 |
|---|---|---|
| 🐚 藤壺 | 低／中／高 | 機關被藤壺黏住不能用，手指在上面來回搓掉 |
| 💧 名牌糊掉 | 中／高 | 自己的機關名字有一半看不清楚，只能靠潛伴喊的名字猜 |
| 🌊 漂走 | 高 | 某個機關被洋流沖到別人畫面上，原本的主人找不到了 |

故障多久出現一次，可以在後台「機關故障間隔秒數」調整（0＝關掉）。

## 賽後精華與成績卡

結算畫面會列出「本局精華」：最慘一刻（10 秒內噴掉最多氣）、最難喊的機關、最佳潛伴、最快的一次等等。
按「📸 存成績卡」會產生一張圖（每個人的稱號＋精華），可以長按存到相簿或直接分享到群組。

## 單人練習

首頁按「🎧 單人練習」，不用等其他人：

- **AI 潛伴用語音喊指令**（龜龜教練、八爪阿姨、膨膨、豆丁鯊），機關都在你自己的畫面上（6 個）
- **計時 3 分鐘**或**無盡下潛**（越來越快，撐到沒氣），分難度記錄最高分（存在自己的手機上）
- 高難度部分指令只有聲音、看不到文字
- 支援語音辨識的手機可開「🎤 我也要喊」：偶爾換你對手機喊指令給潛伴

## 音樂與動畫

全程都有配樂（全部即時合成，不需要音檔）：
- 首頁、大廳、結算：輕鬆的「船上主題曲」（瀏覽器規定要先點一下畫面才會出聲音）
- 開場動畫：船上撥弦 → 撲通下水 → 水下 → 倒數往上推
- 遊戲中：平靜 → 緊張 → 失控三段，每段和弦進行不同，越緊張速度越快；氣量低於 50 bar 會出現心跳鼓；水面休息時退回平靜段
- 三種結局各有一段配樂（安全上升／喘氣上岸／pass out）
- 右上角 🎵 可以開關（遊戲中在計時器旁邊）
- 開場：背滾下水 → 下潛 → 3、2、1 倒數
- 結局：氣量 60 bar 以上「安全上升」、以下「喘氣上岸」、降到 20 bar「pass out」

## 在自己的 Windows 電腦上跑（全班連同一個 Wi-Fi）

1. 到 https://nodejs.org 下載「LTS」版本，一路按「下一步」安裝。
2. 把 `magic-factory` 資料夾解壓縮到桌面。
3. 打開 `magic-factory` 資料夾，在上方網址列輸入 `cmd` 按 Enter，會跳出黑色視窗。
4. 輸入 `npm install` 按 Enter（第一次才需要，等它跑完）。
5. 輸入 `npm start` 按 Enter，看到「🤿 深海大亂潛已開放下水」就成功了。如果 Windows 防火牆跳出詢問，按「允許存取」。
6. 在同一個黑色視窗再開一個新的 cmd，輸入 `ipconfig`，找到「IPv4 位址」（例如 `192.168.1.23`）。
7. 玩家手機打開瀏覽器，輸入 `http://192.168.1.23:3000`（換成你的 IP）。

> **只有幾支手機想先試玩？** 第 5 步改輸入 `set MIN_PLAYERS=2 && npm start`，2 人就能開局。

## 放到網路上（不用同一個 Wi-Fi）

GitHub Pages 只能放純網頁，**跑不了這個遊戲的伺服器**。可以改用 Render（有免費方案）：

1. 把整個資料夾上傳成一個 GitHub repository。
2. 到 https://render.com 用 GitHub 登入 → New → Web Service → 選這個 repo。
3. Build Command 填 `npm install`，Start Command 填 `npm start`，按建立。
4. 完成後會得到一個網址，玩家直接開就能玩。免費方案閒置後會休眠，第一次打開要等約一分鐘。

## 後台（主持人專用）

網址：`你的遊戲網址/admin`，或在遊戲首頁**長按標題「深海大亂潛」3 秒**。預設密碼 `12345678`（可在 Render 的環境變數 `ADMIN_PASSWORD` 改掉）。

- **遊戲參數**：一局時間、開局與結尾的指令秒數（越玩越快）、最低人數、扣分與回復
- **題庫管理**：新增、修改、刪除、停用機關，可匯出／匯入 JSON
- **成績紀錄**：每局結果，可下載成 Excel 能開的 CSV

後台的修改只存在伺服器記憶體，伺服器休眠或更新後會恢復預設。

## 調整難度

打開 `server.js`，最上面的 `CONFIG` 區塊：

| 設定 | 預設 | 意思 |
|---|---|---|
| `INSTRUCTION_MS` | 15000 | 每條指令幾毫秒（15 秒） |
| `WRONG_PENALTY` | 5 | 亂按扣多少穩定度 |
| `WRONG_COOLDOWN_MS` | 1000 | 同一人狂按時，1 秒內只扣一次 |
| `TIMEOUT_PENALTY` | 8 | 指令逾時扣多少 |
| `SUCCESS_BONUS` | 2 | 完成一條指令回復多少 |

## 新增機關

在 `data/devices.json` 照格式加一筆即可，`id` 不能重複：

- `type`：`button`（按鈕）／`switch`（開關）／`slider`（滑桿）／`compass`（指北針，中高難度）／`selector`（選擇器，高難度，要加 `options` 選項清單）
- `target`：按鈕寫 `press`；開關寫 `on` 或 `off`；滑桿寫 `max`（頂）、`mid`（中）、`min`（底）
- 沒寫 `target` 也行，伺服器會從 `action` 文字判斷（「開啟／關閉」「推到頂端／中間／拉到底部」）

題庫至少要 40 個機關才能支援 10 人同時玩。
